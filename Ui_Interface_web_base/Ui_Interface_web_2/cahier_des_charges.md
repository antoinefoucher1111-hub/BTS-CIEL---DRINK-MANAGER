## créer une application pour gérer le café d'une entreprise

compte/solde des consommateurs : argent du ou crédité <br>
interface graphique avec gestion autonome de la consommation + porte-feuille<br>
intégration d'un capteur biométrique + service web accessible via qrcode<br>
choix du modèle de café<br>
sauvegarde dans un fichier xml<br>
créer une bdd, un ORM (charger la bdd en objet)<br>
codage natif / PAS interprété !<br>

3 équipes de 2 qui tournent (pair programming, binomes, ...) :

- utiliser la méthode AGILE, kamban, trello, git, ...
- évaluation par équipe + individuelle (fournir un rapport : choses apprises, comment les choses se sont déroulées, ...) / possible de présenter le rapport à l'oral

## Découpage des équipes :

- Utilisateurs - Interface WEB, UI
- Securité - montage capteur, codage du système profond
- Data - Base de donnée, écriture / lecture
